# Topic 34 — extra judgement checks (read the paper; verdict per item as in the common rubric)

| # | Check | MET when |
|---|---|---|
| T34-J1 | **Readiness is defined and bounded** | The paper defines digital-forensic readiness (ability to collect admissible evidence *before* an incident, at proportionate cost) and states the scope (frameworks, standards, maturity models; organisation types) |
| T34-J2 | **Standards read directly** | ISO/IEC 27043, 27037, 27035 (and 30121 where relevant) and NIST SP 800-61 are discussed from the standards themselves, with what each actually requires, not only via secondary summaries |
| T34-J3 | **Frameworks compared** | Rowlingson's ten-step process and other frameworks/maturity models are compared on a common set of dimensions, not described one by one |
| T34-J4 | **Capabilities taxonomy** | Capabilities (governance, logging, retention, time synchronisation, acquisition, cloud, personnel, testing) are organised into a coherent taxonomy and mapped to the standard that supports each |
| T34-J5 | **RQ1 answered** | Lists which frameworks/maturity models exist and how they group |
| T34-J6 | **RQ2 answered** | Says which capabilities standards and practice support and **how readiness is measured** (scales, anchors, assessors, evidence required) |
| T34-J7 | **RQ3 answered with evidence** | Reports whether any study shows maturity **predicts investigative capability** (outcomes, simulated incidents, inter-rater reliability); honestly states if evidence is absent or weak |
| T34-J8 | **Validation appraisal** | The appraisal specifically judges reliability/validation evidence of each instrument (independent scoring, scenario validation, predictive link) |
| T34-J9 | **Matrix** | Columns include framework, standard basis, measurement method, validation; "not validated" is stated explicitly where true |
| T34-J10 | **Local context** | National guidance (NCA controls; PDPL/Anti-Cyber Crime Law where relevant) is treated accurately, or its omission is justified in the scope |
| T34-J11 | **Measurement agenda** | The conclusion/discussion proposes concrete steps for validating readiness instruments (the expected contribution), not generic future work |
| T34-J12 | **Admissibility link** | Connects readiness capabilities to admissible evidence (chain of custody, evidence handling) rather than treating readiness as general security hygiene |
