# Report template (what the reviewer returns)

Write the report in the student's language (Arabic if the student writes Arabic; keep IDs, section names and requirement quotes in English).
Never include rewritten paper text, suggested sentences or "improved" paragraphs — the course forbids AI-written submissions. Point to **where** and **what** to fix, nothing more.

```
# Compliance report — <topic title>   (stage: draft | final)

## Verdict
READY / NOT READY — <one line>.  Counts: FAIL n · WARN n · MANUAL n.

## Blocking (FAIL) — fix before submission
1. [ID] requirement (source) — evidence (file:line / number) — **How to fix** (direction from `revision-guidance.md`, effort quick/medium/heavy).

## Should fix (WARN)
1. [ID] … (note any that the script flagged but you judged to be false positives, and why)

## Needs a human check (MANUAL)
Similarity < 20 %, no AI-generated text, sources actually read, venue quality, table values true to sources …

## What already meets the requirements
Short list of the strongest passes (word count, template, reference count …).

## Judgement table (rubric J1–J18 + topic items)
| Item | Verdict (MET/PARTLY/NOT MET/CAN'T TELL) | Evidence (section, file:line) | What is missing |
|---|---|---|---|

## Revision plan
Ordered per `revision-guidance.md` §Order of work: 1 … 2 … 3 …  (each step: where → action → how to verify; no replacement text)
```
